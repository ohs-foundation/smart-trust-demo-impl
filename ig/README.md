# IG resources

FHIR example and terminology resources generated by SUSHI from the
[WHO SMART Trust Demonstrator IG](https://github.com/litlfred/smart-trust-demo)
at commit `c355acb` (licence CC0-1.0). They are fictional, TEST ONLY data.

SUSHI and the FHIR packages are pinned by the IG's `tools/ig-gen` lockfiles.

- `./ig/build.sh` regenerates `ig/resources/`.
- `./ig/build.sh --check` fails if the committed files differ from the pinned IG.
